# Chapitre 25 — Acteurs de l'immunité

## 1. Introduction (idée globale)

* Ton corps est entouré de microbes en permanence.
* Il doit faire la différence entre :
  * **le soi** = ce qui appartient à ton corps
  * **le non-soi** = ce qui est étranger (microbes, virus…)
* Le système immunitaire :
  * tolère le soi
  * attaque le non-soi (antigènes)

---

## 2. Soi vs Non-soi

### Le SOI

* Ce sont tes propres cellules.
* Elles possèdent des "étiquettes" (marqueurs) permettant d'être reconnues.

### Le NON-SOI

* Tout ce qui est étranger.
* Exemples : bactéries, virus, pollen, greffes.
* Ces éléments s'appellent des **antigènes**.

---

## 3. Les antigènes (important 🔥)

* Un **antigène** = une molécule étrangère qui déclenche une réponse immunitaire.
* 2 propriétés importantes :
  * **Immunogénicité** → déclenche une réaction
  * **Antigénicité** → peut être reconnu par le système immunitaire
* Sur un antigène :
  * **épitope** = petite zone reconnue
  * **paratope** = partie de l'anticorps qui s'y fixe

---

## 4. Les greffes (à connaître ⚠️)

* **Autogreffe** → sur soi-même
* **Isogreffe** → entre jumeaux identiques
* **Allogreffe** → même espèce mais individu différent
* **Xénogreffe** → espèce différente

---

## 5. Organes lymphoïdes

Les "centres" du système immunitaire.

### Organes primaires

* Là où les cellules sont créées et maturent.
* **Moelle osseuse** → fabrique toutes les cellules + maturation des lymphocytes B
* **Thymus** → maturation des lymphocytes T

### Organes secondaires

* Là où les cellules rencontrent les antigènes (stockage + activation).
* Exemples : ganglions, rate.

---

## 6. Le sang et les cellules immunitaires

### Le sang contient :

* **Globules rouges** (érythrocytes) → transport O₂ / CO₂
* **Globules blancs** (leucocytes) → défense immunitaire
* **Plaquettes** (thrombocytes) → coagulation

### Les cellules immunitaires

* Ce sont les globules blancs.
* 2 types d'immunité :
  * **Immunité innée** (rapide, non spécifique)
  * **Immunité acquise** (spécifique, plus lente)

## Questions / Réponses — Chapitre 25

### Niveau facile

**1. Le système immunitaire sert à quoi ?** → À défendre l'organisme contre le non-soi.

**2. C'est quoi le "soi" ?** → Les cellules du corps.

**3. C'est quoi un antigène ?** → Une molécule étrangère qui déclenche une réponse immunitaire.

### Niveau moyen

**4. Différence immunogénicité / antigénicité ?** → Immunogénicité = déclenche la réponse ; Antigénicité = capacité à être reconnu.

**5. Où maturent les lymphocytes B ?** → Moelle osseuse.

**6. Où maturent les lymphocytes T ?** → Thymus.

### Niveau plus dur

**7. Différence entre épitope et paratope ?** → Épitope = partie de l'antigène ; Paratope = partie de l'anticorps qui se fixe.

**8. Donne 2 types de greffes.** → Autogreffe, allogreffe (entre autres).

**9. Rôle des leucocytes ?** → Défense de l'organisme.

### Niveau contrôle

**10. Pourquoi le corps ne s'attaque pas à lui-même ?** → Grâce aux marqueurs du soi.

**11. Où les lymphocytes rencontrent les antigènes ?** → Dans les organes lymphoïdes secondaires.

**12. Donne les 3 éléments figurés du sang.** → Globules rouges, globules blancs, plaquettes.
