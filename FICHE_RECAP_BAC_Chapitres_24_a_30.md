## ⚡ CHAPITRE 24 — Maladies infectieuses

| | Virus | Bactérie |
|---|---|---|
| Structure | Pas une cellule (ADN ou ARN + capside) | Cellule procaryote (sans noyau) |
| Reproduction | Dépend d'une cellule hôte | Autonome (division cellulaire) |
| Traitement | ❌ Antibiotiques inefficaces | ✅ Antibiotiques |

- **Bactériostatique** = bloque la multiplication
- **Bactéricide** = tue les bactéries
- **Antibiogramme** = choisir le bon antibiotique (grande zone d'inhibition = bactérie sensible)
- **Antibiorésistance** = bactéries résistantes → problème majeur de santé publique
- **Infection nosocomiale** = infection contractée à l'hôpital

## ⚡ CHAPITRE 25 — Acteurs de l'immunité

- **Soi** = cellules du corps (marqueurs du soi) → tolérées
- **Non-soi** = corps étrangers = **antigènes** → attaqués
- **Antigène** = déclenche une réponse immunitaire (immunogénicité + antigénicité)
- **Épitope** = zone de l'antigène reconnue / **Paratope** = zone de l'anticorps qui se fixe
- Types de greffes : autogreffe / isogreffe / allogreffe / xénogreffe
- Organes primaires : moelle osseuse (LB) + thymus (LT)
- Organes secondaires : ganglions, rate (rencontre antigènes)
- Sang : globules rouges (O₂) + globules blancs (défense) + plaquettes (coagulation)

## ⚡ CHAPITRE 26 — Défenses immunitaires & grippe

### Immunité innée (rapide, non spécifique, sans mémoire)
- **Barrières** : peau (sébum, flore), muqueuses (mucus, cils, lysozyme)
- **4 signes de l'inflammation** : rougeur, chaleur, douleur, gonflement (œdème)
  - Cause : vasodilatation + ↑ perméabilité → afflux sang + sortie plasma
- **Phagocytose** (macrophages + polynucléaires neutrophiles) :
  1. Chimiotactisme → 2. Adhésion → 3. Ingestion (phagosome) → 4. Digestion (phagolysosome) → 5. Exocytose

### Immunité acquise (lente, spécifique, avec mémoire)

| | Réponse humorale (LB) | Réponse cellulaire (LT8) |
|---|---|---|
| Cellules | Lymphocytes B → plasmocytes + LB mémoire | Lymphocytes T8 cytotoxiques |
| Action | Produisent des **anticorps** | Détruisent les cellules infectées |
| Mécanisme | Neutralisation, opsonisation, complément | Perforines + granzymes → cytolyse |

- **LT4** = chef d'orchestre → active LB et LT8 via **IL-2**
- **CPA** (macrophage) → présente l'Ag sur CMH → **double reconnaissance** → activation LT4
- **IL-1** (CPA) → amplifie multiplication LT4

### Vaccination vs Sérothérapie
| | Vaccination | Sérothérapie |
|---|---|---|
| Principe | Antigène inoffensif → mémoire immunitaire | Injection d'anticorps tout prêts |
| Protection | Durable | Immédiate mais temporaire |
| Mémoire | ✅ OUI | ❌ NON |

- **Anactorine** = toxine sans pouvoir pathogène mais avec pouvoir antigénique (utilisée en vaccin)
- **Réponse primaire** = lente, peu d'anticorps / **Réponse secondaire** = rapide, nombreux anticorps
- Vaccin grippe renouvelé chaque année car **variabilité antigénique** du virus

### Analyses sanguines
- **NFS** : leucocytose (↑ GB = infection), leucopénie (↓ GB), anémie (↓ hémoglobine)
- **CRP** : produite par le foie ; ↑↑ infection bactérienne ; ↑ modérée infection virale
- **VS** : vitesse de sédimentation des GR ; ↑ lors d'inflammation
- **Sérodiagnostic** : détecte anticorps dans le sérum → séropositif (contact avec agent) / séronégatif (pas de contact)

## ⚡ CHAPITRE 27 — Appareils reproducteurs

### Homme
- Gonades = **testicules** (spermatozoïdes + testostérone)
- Spermatozoïde : 60 µm, 300-400 millions/éjaculation, mobile grâce à l'épididyme, survit 4-5j
- **Sperme** = spermatozoïdes + liquide séminal (vésicules séminales) + liquide prostatique (prostate alcalin)

### Femme
- Gonades = **ovaires** (ovocytes + progestérone + œstrogènes)
- Ovocyte capté par le pavillon, survit 24h, s'arrête dans le tiers supérieur de la trompe

### Méiose ⚠️
- Cellule diploïde (2n=46) → **4 cellules haploïdes** (n=23)
- Méiose I (réductionnelle) : Prophase I = **brassage intrachromosomique** / Anaphase I = **brassage interchromosomique**
- Méiose II (équationnelle)

### Spermatogenèse vs Ovogenèse
| | Spermatogenèse | Ovogenèse |
|---|---|---|
| Début | Puberté | Vie embryonnaire |
| Type | **Continue** | **Discontinue** |
| Durée | 74 jours | Variable |
| Résultat | 4 spermatozoïdes | 1 ovocyte + globules polaires |

- **Spermatocytogenèse** : spermatogonie → spermatocyte I → spermatocyte II → spermatide
- **Spermiogenèse** : spermatide → spermatozoïde (différenciation)
- Cellules de Leydig → testostérone / Cellules de Sertoli → nourricières
- Follicule de De Graaf → ovulation au **14ème jour**
- Corps jaune → progestérone → dégénère si pas de fécondation

## ⚡ CHAPITRE 28 — Grossesse

### Fécondation
- Lieu : tiers supérieur de la trompe
- Étapes : fixation → réaction acrosomiale → fusion membranes (monospermie) → pénétration noyau → **caryogamie** (2n=46)

### De la fécondation à la nidation
- Cellule œuf → mitoses → 2 → 4 → 8 → 16 cellules (**morula**) → **blastocyste**
- Morula atteint l'utérus : 3-4ème jour / Nidation dans l'endomètre : **6ème jour**
- Embryon jusqu'à 8 semaines / Fœtus à partir de la 9ème semaine

### Placenta (barrière sélective)
| Mère → Enfant | Enfant → Mère | Substances nocives (passent) | Ne passent pas |
|---|---|---|---|
| IgG, eau, sels, nutriments, O₂ | CO₂, urée | Alcool, tabac, drogues, médicaments | IgM, IgA |

### Suivi médical
- **Échographie** : ultrasons, non invasif, indolore, sans danger
- **Examens sérologiques** : présence d'anticorps → immunisée ? (ex : toxoplasmose)
- **Amniocentèse** : ponction 15-20 mL liquide amniotique sous contrôle écho → caryotype fœtal ; **risque 1% FC**

### Caryotype ⚠️
- Normal : **22 paires autosomes + 1 paire gonosomes = 46 chromosomes**
- **46, XX** = féminin / **46, XY** = masculin
- Trisomie = 47 chromosomes (ex : trisomie 21 = 47, XY + 21)
- Monosomie = 45 chromosomes (ex : syndrome de Turner = 45, X0)
- Anomalies de structure : Délétion / Inversion / Translocation

## ⚡ CHAPITRE 29 — Régulation de la fonction reproductrice

### Complexe hypothalamo-hypophysaire (dans l'encéphale)
```
Hypothalamus → GnRH → Antéhypophyse → LH + FSH (gonadostimulines)
```

### Régulation masculine ⚠️
```
GnRH → Hypophyse → LH → Cellules de Leydig → TESTOSTÉRONE
                  → FSH → Cellules de Sertoli → ABP
                  Testostérone + ABP → cellules germinales → spermatogenèse
Testostérone (↑↑) → rétrocontrôle négatif sur hypothalamus et hypophyse
Inhibine (Sertoli) → rétrocontrôle négatif sur hypophyse (↓ FSH)
```

### Régulation féminine ⚠️
- Cycle de 28 jours en moyenne :
  - Phase **folliculaire** = **variable** (10-20j) ; follicule sécrète œstrogènes
  - Phase **ovulatoire** = pic de LH → ovulation
  - Phase **lutéale** = **constante 14j** ; corps jaune sécrète progestérone + œstrogènes

| Hormone | Sécrétée par | Rôles |
|---|---|---|
| **Œstrogènes** | Follicule | Prolifération endomètre, mucus cervical, caractères sexuels secondaires |
| **Progestérone** | Corps jaune (phase lutéale) | Aspect en dentelle endomètre, inhibe contractions myomètre, développement glandes mammaires |

### Rétrocontrôles ovariens ⚠️
| Phase | Concentration | Type de rétrocontrôle | Effet |
|---|---|---|---|
| Folliculaire | [œstrogènes] faible | **Négatif** | Freine hypophyse → peu de FSH/LH |
| Avant ovulation | [œstrogènes] forte (> seuil) | **Positif** | Pic de LH → **OVULATION** |
| Lutéale | [progestérone] forte | **Négatif** | Freine hypophyse → ↓ LH/FSH → corps jaune dégénère → nouveau cycle |

## ⚡ CHAPITRE 30 — Maîtrise de la procréation

### Contraception vs Contragestion
- **Contraception** = avant la fécondation (empêche rencontre des gamètes)
- **Contragestion** = après la fécondation (empêche nidation)

### Méthodes clés à retenir
- ✅ Seul le **préservatif** protège contre les IST
- **Pilule combinée** (œstrogènes + progestatifs) → rétrocontrôle négatif → pas de pic LH → pas d'ovulation + anti-glaire + anti-nidatoire
- **Pilule du lendemain** = contragestion d'urgence, dans les **72h**, empêche la nidation
- **Stérilet** = anti-glaire + anti-nidatoire ; déconseillé avant 1er enfant

### Interruption de grossesse
| Type | Délai | Lieu | Principe |
|---|---|---|---|
| **Médicamenteuse** | jusqu'à 7 SA (= 5 sem. grossesse) | Cabinet ou établissement de santé | RU486 (antiprogestatif) + prostaglandines 48h après |
| **Chirurgicale** | jusqu'à 14 SA (= 12 sem. grossesse) | Obligatoirement établissement de santé | Aspiration de l'œuf + dilatation col |
- **IVG** : jusqu'à 12ème sem. de grossesse / **IMG** : jusqu'à la fin de grossesse (maladie grave ou risque mère)

### Infertilité (1/3 féminine / 1/3 masculine / 1/3 inconnue)
- Féminine : causes mécaniques (trompes, glaire), infectieuses (salpingite), hormonales (anovulation)
- Masculine : détectée par **spermogramme** → azoospermie / oligospermie / asthénospermie / tératospermie / hypospermie

### AMP
| Méthode | Pour qui | Principe |
|---|---|---|
| Stimulation hormonale | Anovulation | FSH → follicules mûrs → hCG → ovulation |
| IAC / IAD | Anomalie sperme / glaire / maladie génétique | Dépôt spermatozoïdes par cathéter |
| **FIVETE** | Trompes bouchées, anovulation, anomalies sperme | Fécondation in vitro → transfert embryon (stade 8 cellules) |
| **ICSI** | Infertilité masculine grave | Spermatozoïde injecté **directement** dans l'ovocyte II |

## 🔑 Les 10 points les plus importants à ne jamais confondre

1. **Antibiotiques ≠ virus** — les antibiotiques ne servent qu'à traiter les bactéries
2. **Immunité innée** = sans mémoire / **Immunité acquise** = avec mémoire
3. **LT4** = chef d'orchestre de TOUTE la réponse immunitaire (active LB et LT8)
4. **Méiose** = 4 cellules haploïdes / **Mitose** = 2 cellules identiques diploïdes
5. **Phase folliculaire** = variable / **Phase lutéale** = toujours 14 jours
6. **Corps jaune** = progestérone (uniquement en phase lutéale)
7. **Rétrocontrôle positif** = fort taux d'œstrogènes → pic de LH → ovulation (exception à la règle !)
8. **Placenta** = les 2 sangs ne se mélangent JAMAIS (mais les substances toxiques passent quand même)
9. **FIVETE** = fécondation in vitro / **ICSI** = spermatozoïde injecté directement dans l'ovocyte
10. **Séropositif** = a des anticorps (a été en contact) / **Séronégatif** = pas d'anticorps détectés
