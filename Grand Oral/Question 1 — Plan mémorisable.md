## Intro

IA partout → porno accessible mineurs → ARCOM 2,3M/mois → deepfake (def courte) → santé publique

## I. Phénomène en expansion

1 mineur/3 → 2,3M/mois → dès 12 ans 1/2 garçons → 2/3 chez 16-17 ans → deepfakes (nouveaux contenus) → causes : numérique + IA + manque d'éducation

## II. Conséquences

anxiété, honte, isolement → cyberharcèlement, scolarité → filles + touchées → enjeu santé publique

## III. Réponses des acteurs publics

acteurs : État, ARCOM, Éduc nat, asso, plateformes
→ loi 2020 = vérif âge sites (limite : pas les deepfakes)
→ loi SREN 2024, art. 226-8-1 = deepfakes sexuels (3 ans/75 000€ en ligne ; limite : diffusion punie, pas création)
→ éducation sexualité + numérique
→ limite technique : VPN
→ approche globale (prévention + éduc + accompagnement + régulation)

## Conclusion

enjeu santé publique confirmé → mobilisation coordonnée → prévention, protection, accompagnement
